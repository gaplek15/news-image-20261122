## How it works

`main.py` copies the bundled front page (`news.png`, 1024×1024) to `$MAKEFUN_OUTPUT_DIR/entry.png` without changing a single byte, then re-reads both files and refuses to finish unless size and sha256 match — including a second check that the source did not change mid-copy. No network, no clock, no randomness — fully deterministic. Run it twice and the two outputs are byte-identical.
